# Batch Video Stabilization for Adobe Premiere Pro

The [Batch Video Stabilizer by Vakago Tools](https://vakago-tools.com/batch-video-stabilizer/)
plugin for Premiere allows you to stabilize multiple video clips in Adobe Premiere.

Two versions are available for the newer UXP architecture and the legacy CEP plattform.

**[Download the new UXP version on Adobe Exchange](https://exchange.adobe.com/apps/cc/dec09d85/batch-video-stabilizer)**
· **[Features and more information](https://vakago-tools.com/batch-video-stabilizer/)**

## Download and install

| Your Premiere version      | Extension                                               | Download                                                                                            |
| -------------------------- | ------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Premiere Pro 25.6 or later | Batch Video Stabilizer (new UXP version)                | [Get the UXP version](https://exchange.adobe.com/apps/cc/dec09d85/batch-video-stabilizer)           |
| Older Premiere versions    | Batch Analysis for Warp Stabilizer (legacy CEP version) | [Get the CEP version](https://exchange.adobe.com/apps/cc/107996/batch-analysis-for-warp-stabilizer) |

1. Open the Adobe Exchange listing above and follow the listing's installation instructions through Adobe Creative Cloud.
2. For the UXP version, open Premiere and choose **Window > UXP Plugins > Batch Video Stabilizer**.
   For the legacy CEP version, look under **Window > Extensions** for **Batch Analysis for Warp Stabilizer**.

Visit the [official Batch Video Stabilizer page](https://vakago-tools.com/batch-video-stabilizer/)
for product details and download links.

## Bug reports and feature requests

This repository provides documentation and an issue tracker for Batch Video Stabilizer.

Use this repository's **Issues** tab to report a bug or suggest a feature. Check existing
issues first. For bug reports, include:

- Your Premiere version, operating system and extension version (UXP or CEP).
- Steps to reproduce the problem, expected behavior and what actually happened.
- Any error messages and relevant screenshots.
